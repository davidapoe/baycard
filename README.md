# BAYCARD

Procedure files for light commercial packaged rooftops.

Search a nameplate. Run a version that already closed. If the roof was different, publish a new one.

Not a feed. Not a chatbot.

## Screens

1. **Pull** — search by model. Files ranked by reuse, not recency.
2. **File** — work card: fault, conditions, steps, parts, photos, outcome.
3. **Log** — end of job, about 60 seconds. The write path.
4. **Shop** — today’s units and the files you pulled.

Beachhead: Carrier, Lennox, Trane, York RTUs.

## Run

```bash
npm install
npm run dev
```
